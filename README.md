# Git 仓库管理工具（GitTool）

一个面向 **Windows 桌面** 的轻量级 Git 可视化管理工具，用 C# / .NET 10 (WinForms) 编写。
目标是把日常最高频的 Git 操作（提交、推送、拉取、分支、比对、回退）收敛到一个窗口里，
并且**原生内置「提交即推送 + 失败自动重试 + 远程状态追踪」**，让本地与远程的同步状态一目了然。

> 适合：需要频繁提交、多终端协作、又不想每次敲命令的开发者；也适合作为团队内部的轻量 Git 入口。

---

## ✨ 功能特性

### 仓库管理
- **历史仓库记忆**：识别成功的仓库自动记录，下次从下拉框直接选择，支持自动补全、回车加载、一键「移除记录」（LRU 上限 15 条）。
- 标题栏实时显示当前仓库名与分支。

### 提交与远程同步
- **提交并推送**：本地提交成功后自动推送到远程（首次自动 `--set-upstream`）。
- **自动重试机制**：推送失败时对「瞬时错误」（网络不可达 / 超时 / 连接中断 / SSL 握手失败等）自动重发，最多 3 次、间隔 1.5 秒；对「远程分叉被拒」这类重试也无用的情况**不盲目重试**，直接提示先拉取。
- **手动重试入口**：「重试推送（同步远程）」按钮，随时可重新发起当前分支推送。
- **远程提交状态列**：提交明细列表实时展示每一次提交是否已同步到远程：
  - 🟢 **已同步**（绿）—— 本地提交已存在于远程
  - 🟠 **未推送**（橙）—— 本地有提交但远程还没有
  - ⚪ **无远程**（灰）—— 仓库未配置远程
  - 🔴 **推送失败（需重试）**（红 + 加粗）—— 最近一次推送失败，待处理
  - 状态以 `git rev-list <upstream>` 可达性比对为真相来源，每次刷新都是实时的，不会过期。
- **拉取当前分支**：`pull --ff` 同步远程最新提交。
- **获取远程分支**：列出 `origin/*`，新建跟踪分支并切换，幂等（已存在则跳过）。

### 变更比对（DiffView）
- 支持三种比对维度：**工作区 vs 暂存/HEAD**、**某次提交 vs 其父提交**、**两次提交之间**。
- 展示每个文件的改动类型（新增 / 修改 / 删除 / 重命名）、增删行数统计，以及具体 patch 内容。

### 版本回溯
- **撤销此提交（安全）**：以 revert 方式安全回退，不破坏历史。
- **回到此提交（保留改动）**：软重置，改动保留在工作区。
- **回到此提交（丢弃改动）**：硬重置（高危）。
- **丢弃未提交改动**：还原工作区。
- **新建分支 / 切换分支或提交 / 打标签**。
- 所有高危操作（红按钮）执行前**自动 stash 备份**，降低误操作风险。

## 🔧 构建与运行

```bash
# 1. 克隆仓库
git clone https://github.com/xujingyi002/GitTool.git
cd GitTool

# 2. 还原并构建
dotnet build -c Release

# 3. 运行（Debug 也可）
dotnet run -c Release
# 或直接启动生成的 exe：
# bin\Release\net10.0-windows\GitTool.exe
```

若仅需使用，可直接运行已编译的 `GitTool.exe`（需本机具备 .NET 10 运行时）。

## 📖 使用说明

1. **打开仓库**：通过「浏览…」选择 Git 仓库目录，或下拉框选择历史仓库。识别成功后会自动记录。
2. **提交**：在下方填写提交说明，点击「提交并推送」。本地提交成功后自动推送；推送失败会在状态栏与对应行标红提示。
3. **追踪同步状态**：查看「远程提交状态」列与状态栏汇总（如 `远程：已同步 3 / 未推送 1`）。
4. **处理失败**：若推送因网络瞬时失败，工具会自动重试；若因远程分叉失败，先点「拉取当前分支」合并，再点「重试推送（同步远程）」。
5. **比对改动**：选中某次提交，点「查看提交的改动」查看该提交的文件级与行级差异。
6. **回溯**：按需使用「撤销此提交 / 回到此提交 / 丢弃改动」等按钮，高危操作会先自动备份。

## 🧩 项目结构

```
GitTool/
├── Program.cs          # 应用入口（STA 线程，启动主窗体）
├── MainForm.cs         # 主窗体：仓库选择 / 操作面板 / 提交明细网格
├── GitService.cs       # Git 命令封装：日志 / diff / 远程同步 / 状态判定
├── DiffView.cs         # 变更比对页（双提交下拉 + 文件/行级差异）
├── RepositoryStore.cs  # 历史仓库记忆（%APPDATA%/GitTool/recent-repos.txt）
└── GitTool.csproj      # .NET 10 WinForms 工程
```

---

## ⚠️ 已知限制 / 说明

- 当前为**个人/演示级工具**，不内置账号体系或权限控制；远程仓库的认证依赖本机已配置的 Git 凭据（HTTPS Token 或 SSH）。
- 远程同步判定以本地 `git` 对 `upstream` 的可达性为准；若远程分支名与本地不一致，请先用「拉取当前分支」对齐。
- 工具不修改仓库之外的任何全局 Git 配置。
